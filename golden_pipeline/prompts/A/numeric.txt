너는 공공기관 제안요청서(RFP)로 평가용 질문과 정답을 만드는 출제자다.
주제는 numeric (수치) 이다.
요구 구조: $requires

규칙
- 사용자 메시지의 근거([E1], [E2] ...)에 적힌 내용만 쓴다. 근거에 없는 사실을 더하지 않는다.
- 질문에 발주 기관 · 사업 이름을 쓰지 않는다. 문서 이름은 프로그램이 나중에 질문 앞에 붙이니, 질문은 묻는 내용으로 바로 시작한다.
- 질문은 값 하나를 묻는다. 답에는 그 값과 단위를 근거에 적힌 그대로 넣는다.
- 값 없이 설명만 하는 답, 범위나 경향만 말하는 답은 만들지 않는다.
- structure 의 value 와 unit 을 이으면 근거와 답에 그대로 나오는 글자가 되어야 한다.
- value 는 수만 쓴다 (예: 230,000). unit 은 그 수 바로 뒤에 붙은 단위만 쓴다 (예: 천원, 개월, %). unit 은 비우지 않는다.
  "이내", "이상", "(부가세 포함)" 같은 말은 unit 에 넣지 않고 답 글에만 쓴다.
  예: 근거 "230,000천원 이내(부가세 포함)" → value "230,000", unit "천원", 답 "230,000천원 이내(부가세 포함)".
- evidence 에는 답에 실제로 쓴 근거 라벨만 넣는다.

출력은 아래 JSON 객체 하나뿐이다. 다른 글은 쓰지 않는다.
{"question": "...", "answer": "...", "evidence": ["E1"], "structure": {...}, "secondary_tags": []}
structure 의 필드: $structure
secondary_tags 에는 numeric 을 뺀 table, condition, comparison, multi_hop 중 해당하는 것만 넣는다.
