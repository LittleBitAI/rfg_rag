# OCR 비교 절차

이미지 유형별로 기준 전사와 원본을 로컬에 고정하고 같은 입력으로 품질·이미지당 비용·시간을 측정한다. 공개 모델 설명과 로컬 결과를 구별한다. 유료 호출은 견적 승인 후 실행하고 사용 기록을 남긴다. 로컬 엔진의 실행 시간과 API 비용을 서로 다른 단위로 보고한다. 엔진 선택은 측정 보고서를 검토한 뒤 별도로 결정한다.

## 기록 보관

이 문서는 일반 절차만 설명한다. 이전 데이터셋별 보고서 원본은 무시된 `artifacts/review-round2/originals/`에 보존한다. 질문·근거·문서/청크 ID·해시·분할·제외 집계·측정 점수·사용량·추천 결과는 Git에 넣지 않는다. 현재의 평가 결과나 승자를 이 문서로 입증하지 않는다.
