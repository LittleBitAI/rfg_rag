# 수량 필터 검증 견적 절차

실행할 질문·모델·호출 상한·입력 및 출력 토큰 가정을 비공개 로컬 계획에 고정한다. config의 단가와 캐시 가정을 적용해 작업 전체 예상액을 제시하고 승인 전에 유료 호출하지 않는다. 재시도와 앞선 실행 비용을 같은 로컬 장부에서 추적한다. 미측정 값을 실제 지출로 표시하지 않는다.

## 기록 보관

이 문서는 일반 절차만 설명한다. 이전 데이터셋별 보고서 원본은 무시된 `artifacts/review-round2/originals/`에 보존한다. 질문·근거·문서/청크 ID·해시·분할·제외 집계·측정 점수·사용량·추천 결과는 Git에 넣지 않는다. 현재의 평가 결과나 승자를 이 문서로 입증하지 않는다.
