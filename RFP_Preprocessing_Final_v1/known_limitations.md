# 알려진 한계

- CONDITIONAL PASS는 저장된 요소·청크 계약과 재현 가능성에 대한 판단입니다. 운영 DB, active_run, Dense/Hybrid, 실제 Generation은 검증하지 않았습니다.
- 신규 HWP 검증은 원본 OLE BodyText의 표/셀 구조 숫자와 주소를 직접 읽은 B 수준입니다. 텍스트 디코더는 pyhwp 계열로 Native와 계보가 같아 완전히 독립된 이중 파서 검증은 아닙니다. 전체 원본 화면 검증을 주장하지 않습니다.
- 9,034개 원본-Native 일치 표 중 대응 모호/전체 요소 불일치 3,416, 단일 셀 638, 동일 내용 복수 후보 10, 순서 충돌 2, 기존 검증 유지 1개를 신규 적용에서 제외했습니다. 추가 58개는 고정 청커 출력에서 셀 전체 텍스트 보존을 입증하지 못해 기존 검증된 결합본 표현으로 되돌렸습니다. 원인 확정 전 텍스트 누락이라고 단정하지 않습니다. 중첩/불완전 격자는 9,034개 검증 집합 진입 전에 제외됐습니다.
- Native 성공 PDF 4문서는 신규 확대 대상이 아닙니다. 기존 IBS 표5 및 원본 검증 제목·목차 결합은 유지합니다.
- AFSIS/MILE은 기존 검증된 개선본의 검증된 범위만 유지합니다. 두 문서 전체 표·중첩 구조가 완전히 복원됐다고 주장하지 않습니다.
- 청커 table_rows()는 rowspan 셀 텍스트를 덮는 각 행에 반복합니다. 이는 고정 청커의 표현이며 원본 레코드나 parent/child의 중복 등록은 없습니다. quote는 텍스트 렌더링이라 원본 격자/병합 구조를 완전히 표현하지 못합니다. 행 경계/제목을 포함한 전체 구조는 element.table.cells와 structure_mapping을 함께 보십시오.
- 최종 요소의 raw/search 텍스트는 그대로지만 청커는 cells에서 body를 다시 렌더링하므로 payload·순위·quote가 달라집니다. 절대 BM25 점수만으로 개선을 판단하지 않았습니다.
- unit_limit=6에서 Dev55 Packed Complete 53/55, 기존6은 5/6입니다. 과거 다른 상한에서 관측한 55/55와 조건이 다릅니다. 이번 최종본은 unit_limit=20을 새로 측정하지 않았습니다.
- 개발 중 사용한 61문항의 회귀만 확인했습니다. 독립 일반화 성능, 실제 LLM 정답 품질 향상, Native 전체 대비 우월성은 입증되지 않았습니다.
- 문서 원본 파일은 포함하지 않았으며 source SHA와 구조 주소로 역추적합니다. 새로운 문서에 자동 적용하는 범용 결합 어댑터가 아닙니다.
