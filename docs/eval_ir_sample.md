# 개발 검색 평가 절차

개발 질문의 선정 규칙과 원본을 로컬 manifest에 고정한다. 문서·청크별 완전 라벨 여부를 구분하고 부분 라벨은 해당 수준의 분모에서 제외한다. Recall·MRR은 패킹 전 청크 위치로, Coverage는 실제 컨텍스트로 계산한다. 개발 표본의 결과를 최종 테스트 결과로 부르지 않는다. 유료 재작성·생성·심판 호출은 config 단가로 견적을 제시하고 승인받은 뒤 실행한다.

## 기록 보관

이 문서는 일반 절차만 설명한다. 이전 데이터셋별 보고서 원본은 무시된 `artifacts/review-round2/originals/`에 보존한다. 질문·근거·문서/청크 ID·해시·분할·제외 집계·측정 점수·사용량·추천 결과는 Git에 넣지 않는다. 현재의 평가 결과나 승자를 이 문서로 입증하지 않는다.
