# 수량 필터 검증 절차

운영 색인을 변경하기 전에 격리된 색인과 합성 표로 단위·전체 사업 합계·빈 값·정렬·동률·기관 라우팅을 검사한다. 검색이 수량 필터 경로를 사용하는지 후보 순위와 구분해 기록한다. 모델 의존 벡터를 바꾸면 임계값 전송의 한계를 기록한다. 유료 답변 검증은 별도 견적 승인 뒤 수행하고 실측 원본은 artifacts에 보관한다.

## 기록 보관

이 문서는 일반 절차만 설명한다. 이전 데이터셋별 보고서 원본은 무시된 `artifacts/review-round2/originals/`에 보존한다. 질문·근거·문서/청크 ID·해시·분할·제외 집계·측정 점수·사용량·추천 결과는 Git에 넣지 않는다. 현재의 평가 결과나 승자를 이 문서로 입증하지 않는다.
