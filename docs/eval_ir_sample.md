# IR 평가 — dev 30문항 확인

상태: 구현·오프라인 확인 후 유료 표본 실행 승인을 기다립니다. 아래 견적은 실제 실행 비용이 아닙니다.
test 검색·생성·심판은 실행하지 않습니다.

## 입력과 표본

기존 03 출력의 골든 dev 384문항에서 30문항을 선택했습니다. YAML은 표본에 넣지 않습니다.
각 주제에서 ID 순으로 정렬한 뒤 seed 42로 비복원 추출하며, 청크 지표를 확인할 수 있도록
답할 수 있는 주제는 가능한 경우 전체 근거가 라벨된 질문 두 개를 먼저 예약합니다.
이 표본은 라벨된 사례를 의도적으로 포함하므로 전체 dev 정확도 추정치가 아닙니다.

주제별 제외 집계는 같은 폴더의 `planned_exclusions.csv`에 보관합니다.

원본 CSV·기관 값·검색기 라우팅 규칙은 바꾸지 않았습니다. KURE 로컬 모델과 현재 FAISS 색인으로
API 없이 색인 로딩·검색을 확인했습니다. Langfuse 키는 빈 값으로 두어 키 없는 경로를 확인합니다.

## 승인 전 비용 견적

`config.yaml`의 rewrite·llm·evaluation은 모두 gpt-5-mini이며,
입력/캐시 입력/출력 단가는 100만 토큰당 $0.25/$0.025/$2.00입니다.
비용은 `(입력-캐시입력)×입력단가 + 캐시입력×캐시단가 + 출력×출력단가`를 100만으로 나눕니다.
추론 토큰은 출력에 이미 포함되어 이중으로 더하지 않습니다.

| 단계 | 예상 호출 수 | 30문항 예상 USD |
| --- | --- | --- |
| 04 rewrite | 30 | 0.016097 |
| 04 answer | 30 | 0.033952 |
| 05 faithfulness | 60 | 0.061755 |
| 05 factual_correctness | 120 | 0.078725 |
| 합계 | 240 | 0.190529 |

토큰량과 심판 호출 수는 이전 16문항 실행의 `artifacts/retrieval-port-r2-comparison/after/artifacts/api_usage.csv`를 기준으로 합니다.
rewrite는 예제 호출을 포함한 17행의 호출당 평균을 30회로, answer는 16행의 호출당 평균을 30회로 환산했습니다.
심판은 그 실행의 문항당 사용량을 30문항으로 환산했습니다. 각 행의 토큰을 현재 config 단가로 다시 계산한 견적이며
새 질문의 길이·출력·컨텍스트·이전 대화·재시도에 따라 실제 비용은 달라집니다. 보장 상한이 아닙니다.
별도 폴더의 `api_usage.csv`로 이번 실행만 분리해 실제 비용을 보고합니다.

## 승인 후 기록할 결과

동일한 30개 answers 행을 네 함수가 읽습니다. `retrieval.csv`와 문서·청크 성분 표에서
k=5/10/20의 Recall·MRR 및 exact-code 집합 포함률을 보고하고, 단일/다중 근거별
Evidence Coverage·전체 포함률·채점 문항 수를 기록합니다. MRR을 다중 근거 완전성으로 해석하지 않습니다.
현재 설정과 dense_weight=0.5의 검색 전용 재실행을 비교해 저장 rewrite 재사용과 무과금 경로를 확인합니다.
재실행 전후 api_usage 행 수가 같아야 합니다. 변경한 컨텍스트로 기존 답변의 유료 심판을 다시 돌리지 않습니다.

실제 생성·심판 비용과 API 없이 재채점한 결과는 실행 후 이 문서에 추가합니다.
